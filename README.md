# Мёртвый край

Кооперативный зомби-выживач в браузере в духе **7 Days to Die** с low-poly графикой как в **Unturned**.
Работает прямо со статического хостинга (GitHub Pages): без сервера, без установки, до **10 игроков** по коду комнаты.

## Что есть

- **Один остров 3000 × 3000 м с тремя биомами**: на севере — Снега (Мёртвый город, горы, самые опасные зомби и лучший лут), в центре — Лес (деревни, озёра, спокойнее всего), на юге — Пустыня (каньоны, руда, мало воды). Биомы плавно переходят друг в друга. 15 городов, дороги, военная база, места крушения, хижины, заправки, брошенные машины.
- **Сложность мира** на выбор: лёгкая, нормальная, тяжёлая.
- **Смена дня и ночи**: сутки длятся 20 минут — гранёное небо с рассветами и закатами, плывущие полигональные облака, звёзды и луна. Ночью темно и зомби быстрее.
- **Детальные модели**: у людей и зомби — лица, причёски, карманы, шнурованные ботинки, рюкзаки и разгрузки; у зомби рваная одежда, раны и рёбра, у боссов фартук с тесаком, длинные волосы, шипы и когти. Оружие собрано из десятков деталей (прицелы, магазины, цевья, глушители), от первого лица его держат двумя руками. Дальние зомби автоматически упрощаются.
- **Выживание**: здоровье, выносливость, голод и жажда. В пустыне сильнее хочется пить, в снегах — есть. Пить можно из озёр.
- **Добыча ресурсов**: деревья → древесина, камни → камень, рыжие залежи → железная руда, кусты → волокно и ягоды. Топор и кирка добывают в разы быстрее.
- **Крафт у станций**: верстак, кузница (плавка железа), костёр (готовка). 40+ рецептов: инструменты, патроны, оружие, блоки.
- **Строительство баз**: блоки из дерева, камня и железа, стены, окна, рампы, полы, двери, шипы, ящики, спальник (точка возрождения), факелы, грядки с картофелем, сборщик воды. Зомби ломают стены, молоток чинит.
- **Зомби**: ходоки, бегуны, громилы, солдаты. Поиск пути вокруг зданий, реакция на выстрелы, атаки на постройки.
- **Боссы**: Мясник (удар по площади, крушит стены), Крикунья (зовёт подмогу), Прыгун (прыжок на 20 м). У каждого своё логово на карте, а в кровавую луну босс приходит вместе с ордой. С боссов падают трофеи для лучшего оружия.
- **Кровавая луна** каждую 7-ю ночь: орда идёт прямо к игрокам.
- **Оружие**: нож, бита, топоры, кирки, мачете, молоток, пистолет, ПП, дробовик, автомат, бесшумный АС «Вал» (записанный звук выстрела), снайперская винтовка с прицелом. Удары кулаками — поочерёдно левой и правой.
- **Прокачка**: уровень персонажа за убийства, добычу и задания; задания-подсказки ведут от первого топора до 28 дней выживания.
- **Тестовый мир ∞**: кнопка в меню — тот же остров с отдельным сохранением, все шесть стволов и железные инструменты сразу на панели, патроны бесконечные (перезарядка не нужна). Основной мир не затрагивается.
- **Автосохранение**: мир хоста (постройки, ящики, вырубленные деревья, время) и персонажи сохраняются в браузере каждые 30 секунд, на рассвете, при сворачивании вкладки и выходе.

## Управление

| Клавиша | Действие |
|---|---|
| W A S D, Shift, Пробел, C | движение, бег, прыжок, присесть |
| ЛКМ / ПКМ | удар, выстрел, использовать / прицел |
| R | перезарядка, поворот блока при строительстве |
| E | обыскать, открыть, попить воды, собрать урожай |
| 1–8, колесо | слоты хотбара (пустой слот — кулаки) |
| Tab или I | инвентарь и крафт (в нём: клик — взять/положить, Shift+клик — переложить, Ctrl+клик — разделить, наведи + 1–8 — в хотбар, Q — выбросить, Esc — закрыть) |
| M | карта |
| F | фонарик |
| Q | выбросить предмет |
| Enter | чат |
| Esc | пауза |

## Свои звуки выстрелов

Положи файл в папку `assets/sfx/` с именем оружия — игра сама подхватит его вместо синтезированного звука
(подходят `.wav`, `.mp3` и `.ogg`; тишину перед выстрелом лучше обрезать):

| Оружие | Файл |
|---|---|
| Пистолет | `assets/sfx/pistol.wav` |
| Пистолет-пулемёт | `assets/sfx/smg.wav` |
| Дробовик | `assets/sfx/shotgun.wav` |
| Автомат | `assets/sfx/rifle.wav` |
| АС «Вал» | `assets/sfx/asval.wav` |
| Снайперская винтовка | `assets/sfx/sniper.wav` |

Сейчас все шесть — записанные звуки, синтез остаётся запасным вариантом, если файла нет.

## Мультиплеер

Один игрок создаёт мир с галочкой «Открыть мир для друзей» и сообщает остальным **код комнаты** из 5 символов.
Друзья жмут «Подключиться к другу» и вводят код. Соединение напрямую между браузерами (WebRTC через [PeerJS](https://peerjs.com/)),
публичный сервер PeerJS нужен только для «рукопожатия». Хост считает зомби, лут и постройки — пока он в игре, мир открыт.

Ограничения: если у кого-то строгий NAT (некоторые мобильные операторы), прямое соединение может не установиться — тогда лучше подключаться через Wi-Fi.
Свёрнутая вкладка хоста продолжает работать, но не закрывайте её.

## Как выложить на GitHub Pages

1. Создайте на GitHub пустой репозиторий (например, `deadland`).
2. Загрузите в него содержимое этой папки:
   ```bash
   git remote add origin https://github.com/<ваш-логин>/deadland.git
   git push -u origin main
   ```
3. В репозитории откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
   Workflow `.github/workflows/pages.yml` сам опубликует игру при каждом push в `main`.
4. Через минуту игра будет доступна по адресу `https://<ваш-логин>.github.io/deadland/`.

Сборка не нужна: это обычные HTML/CSS/JS-файлы, three.js и PeerJS грузятся с CDN jsDelivr.

## Локальный запуск

Нужен любой статический сервер (модули не открываются через `file://`):

```bash
python tools/serve.py 8765
```

Затем откройте http://localhost:8765/.

## Устройство кода

- `src/world.js` — генерация острова: биомы, рельеф, города, дороги, постройки, ресурсы по чанкам (детерминированно по сиду, поэтому у всех игроков мир одинаковый).
- `src/chunks.js` — отрисовка чанков одним мешем на слой (low-poly с гранями).
- `src/prefabs.js` — дома, магазины, полиция, склады, многоэтажки, военная база.
- `src/physics.js` — столкновения с рельефом и коллайдерами, лучи.
- `src/zombies.js` — ИИ зомби и боссов (на хосте), A* по сетке, отрисовка у всех.
- `src/blocks.js` — строительные блоки и станции.
- `src/game.js` — игровая сессия, протокол хост/клиент, сохранения.
- `src/net.js` — P2P-сеть через PeerJS.
- `src/ui.js`, `index.html`, `style.css` — интерфейс.
